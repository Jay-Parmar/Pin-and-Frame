# TravelMap

A personal travel map. It puts every place you've been on a map with a timeline, plus a photo collection for each place, built from Instagram and phone photos. It runs on infrastructure that costs $0.

**Status (2026-11-22):** planning only, no code yet. The infrastructure has been researched and a stack recommended. One question to you is still open.
